

# 📋 Cadastro de Funcionários

Projeto simples de **CRUD de Funcionários** utilizando **HTML, CSS e JavaScript puro**, com armazenamento local via `localStorage`.  
Ideal para treinar manipulação de DOM, uso de modais e persistência de dados no navegador.

## ✨ Funcionalidades

- ✅ **Cadastrar** funcionário com nome, função e salário  
- ✏️ **Editar** informações de um funcionário existente  
- 🗑️ **Excluir** funcionários da lista  
- 💾 **Salvar automaticamente** os dados no `localStorage`  
- 🖱️ Interface com **modal** para inserção e edição dos dados  

---

## 🧪 Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript  
- [Boxicons](https://boxicons.com/) – ícones para os botões de ação

## 📁 Estrutura do Projeto

```
📦 crud-funcionarios
├── index.html        # Estrutura principal da página
├── styles.css        # Estilização da interface
├── script.js         # Lógica de funcionamento do CRUD
```

---

## 💡 Observações

- Os dados são armazenados localmente via `localStorage`.
- As informações permanecem após recarregar a página.
- Caso o cache do navegador seja limpo, os dados serão perdidos.
